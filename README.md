# R6S Squad Challenge Generator

A tactical, neon-themed randomizer for **Rainbow Six Siege**. Generate random operators and specific gameplay handicaps (challenges) for you and your squad.

## 🚀 Features
- **Dual Randomizer**: Get an Attacker/Defender pair and two unique challenges in one click.
- **Cyberpunk UI**: Visuals designed to match the R6S tactical aesthetic.
- **Mobile Friendly**: Responsive grid layout for use on phones while gaming.

## 🛠️ Tech Stack
- HTML5 / CSS3 (CSS Grid & Flexbox)
- Vanilla JavaScript (ES6+)

## 📦 How to use
1. Clone the repo.
2. Open `index.html` in any browser.
3. Or view it via **GitHub Pages**.
